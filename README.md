# Research site: study session tracker

Static site for the IS218 Plan review. No build step, no framework.

## Files
- `index.html`: the whole site (one page)
- `style.css`: styles (light and dark mode)

## Before you publish
1. Search `index.html` for the highlighted placeholders (`class="todo"`) and fill each one in.
2. Open each source, read it, and enter the date you actually checked it.
3. Replace the repository and career-site links.
4. Preview locally: open `index.html` in a browser.

## Publish on GitHub Pages
1. Put `index.html` and `style.css` in your repository, either in the root or in a `docs/` folder.
2. On GitHub: **Settings → Pages → Build and deployment → Deploy from a branch**.
3. Choose your branch (usually `main`) and the folder (`/ (root)` or `/docs`), then save.
4. After a minute or two, your URL appears at the top of the Pages settings, usually `https://YOUR-USERNAME.github.io/YOUR-REPO/`.
5. Submit that URL and the repository URL in Canvas.

## Keep it honest
- Mark a check as **observed** only after you ran it and have the result.
- Every fact needs a source you read. Anything else goes under interpretation or assumption.
- Update the AI table as you verify each claim.
